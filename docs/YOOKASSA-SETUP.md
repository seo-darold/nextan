# Настройка ЮKassa для пополнения баланса

## 1. Переменные окружения

В `.env` в корне проекта (рядом с `manage.py`) добавьте:

```
YOOKASSA_SHOP_ID=ваш_идентификатор_магазина
YOOKASSA_SECRET_KEY=ваш_секретный_ключ
```

Значения берутся в [личном кабинете ЮKassa](https://yookassa.ru/my): Настройки → Ключи API (или «Показать» у секретного ключа в разделе с API).

## 2. URL уведомлений (webhook)

В личном кабинете ЮKassa укажите URL для уведомлений о платежах:

- **URL**: `https://ваш-домен.ru/payment/yookassa/notify/`
- **События**: включите «Платёж совершён» (payment.succeeded)

Без этого шага баланс не будет зачисляться автоматически после оплаты (пользователь увидит платёж в истории, но сумма попадёт на счёт только после настройки webhook или ручного подтверждения).

## 3. Режим без ЮKassa

Если `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` не заданы, пополнение работает в **демо-режиме**: платёж сразу помечается как завершённый и сумма добавляется на баланс без реальной оплаты (удобно для разработки).

## 4. Тестовые платежи

В тестовом режиме ЮKassa можно использовать [тестовые карты](https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing) для проверки сценариев успешной и неуспешной оплаты.
