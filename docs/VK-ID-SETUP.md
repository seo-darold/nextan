# Настройка входа через VK ID

Код на стороне проекта уже реализован. Чтобы вход через VK ID заработал, нужно выполнить шаги ниже.

## 1. Приложение VK ID

1. Зайдите в [Кабинет разработчика VK](https://id.vk.com/about/business/developers) (или [dev.vk.com](https://dev.vk.com)).
2. Создайте приложение или откройте существующее (в коде используется App ID **54440895** — при необходимости его можно сменить через переменную окружения).
3. В настройках приложения найдите раздел **OAuth / Redirect URI** и укажите **наш callback-URL** (на него VK перенаправляет браузер с кодом авторизации в адресе):
   - Продакшен: `https://nextanalytics.ru/auth/vk-id-callback/`
   - Локально: `http://127.0.0.1:8000/auth/vk-id-callback/`
   Важно: не используйте `/dashboard/` — иначе неавторизованный пользователь попадёт на страницу входа с кодом в URL.
4. Сохраните настройки.
5. Скопируйте **Секрет приложения** (Client Secret) — он понадобится для бэкенда.

Важно: значение **Redirect URI** в кабинете VK должно **полностью совпадать** с тем, что реально открывается после входа (включая слэш в конце, если он есть). Иначе VK вернёт ошибку при обмене кода на токен.

## 2. Переменные окружения

Добавьте в `.env` (или в переменные окружения сервера):

```bash
# Обязательно: секрет приложения VK ID (из кабинета разработчика)
VK_CLIENT_SECRET="ваш-секрет-приложения"

# По желанию: если App ID другой (по умолчанию 54440895)
# VK_APP_ID=54440895

# По желанию: фиксированный redirect URL (иначе берётся /auth/vk-id-callback/ для текущего хоста)
# VK_AUTH_REDIRECT_URL=https://nextanalytics.ru/auth/vk-id-callback/
```

Без `VK_CLIENT_SECRET` кнопка «Войти через VK» будет показываться, но при нажатии бэкенд вернёт «VK ID не настроен».

## 3. Миграции

Выполните миграции (если ещё не выполняли):

```bash
python manage.py migrate
```

Будет создана модель `core.VKIdLink` для привязки аккаунта VK к пользователю Django.

## 4. Поведение

- В модалке входа из шапки по кнопке **VK ID** контент заменяется на виджет VK; после успешного входа выполняется редирект в личный кабинет (или на URL из параметра `next`).
- На странице `/login/` кнопка **«Войти через VK»** открывает отдельную модалку с виджетом VK.
- При первом входе через VK создаётся пользователь (по email из VK или с placeholder-email), привязка `VKIdLink`, а также записи `PersonalData` и `AccountBalance`.
- Если пользователь с таким email уже есть, аккаунт привязывается к нему по VK ID.
- Корзина из сессии при входе через VK переносится в аккаунт пользователя (как при входе по email или Google).

## 5. Проверка

1. Убедитесь, что в кабинете VK указан правильный Redirect URI.
2. Задайте `VK_CLIENT_SECRET` и перезапустите приложение.
3. Откройте сайт, нажмите «Войти» → «VK ID», выполните вход в VK и проверьте редирект и создание/привязку пользователя.

Если при обмене кода на токен приходит ошибка от VK, проверьте совпадение Redirect URI и корректность App ID и секрета.
